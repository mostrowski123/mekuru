Privacy Policy

Effective: July 12, 2026

Data Stored on Device

All core reading data - books, dictionaries, saved words, and reading progress - is stored locally on your device. Mekuru does not upload, sync, or transmit that core reading data to any server.

OCR Accounts and Authentication

Mekuru does not require registration to use its core reader, dictionary, and vocabulary features. When you use OCR features, the app uses Firebase Authentication to create an app-specific authenticated identity. This may be an anonymous account created automatically for OCR usage, or a Google-linked account if you choose to link one to restore a Pro purchase.

Crash Reporting and Feedback

Mekuru uses Sentry for crash reporting and user-submitted feedback. When a crash occurs or you submit feedback, diagnostic information may be sent to Sentry, including stack traces, device model, operating system version, and a randomly generated installation identifier that is not linked to your name or email. This data is used only for debugging and improving the app and is not used for advertising or behavioral tracking.

Usage Statistics

Mekuru collects anonymous usage statistics to understand which features are used and how well they perform - for example, how often the reader, dictionary, OCR, and Anki export features are used, how long operations take, and aggregate install statistics such as library size and number of saved words. This data is sent to Sentry and Google Firebase Analytics together with general device information and a randomly generated installation identifier. It never includes book titles, file names, page content, or the words you look up.

OCR Data

When you use OCR, page images and related OCR requests are sent only to the custom OCR server you configure. Mekuru does not provide or operate an OCR processing server. Any OCR images or request data sent during remote OCR are handled by the server you choose, under that server operator's own policies and retention practices.

Third-Party Services

In addition to Sentry, Mekuru uses Firebase Authentication for OCR features, Firebase Analytics for usage statistics, and may contact Google Play billing services for Pro purchases on Android. These services are used only to support Pro access, purchase restoration, billing state, OCR-related authentication, and the usage statistics described above.

No Advertising or Data Sale

Mekuru does not include advertising SDKs. Crash reports and usage statistics are used only to improve the app - they are never used for advertising, sold, or shared with data brokers.

Changes to This Policy

If this policy is updated, the changes will be reflected on this page.
